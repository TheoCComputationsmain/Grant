# Stripe & E-Commerce Refund Guard

Every customer refund and charge gets one human yes before it happens.

This public Static Space packages the HuggingChat assistant blueprint for Grant's zero-custody consent gate.

- System instructions are embedded verbatim in `index.html`.
- Tools / OpenAPI action: https://grant-approve.vercel.app/openapi.json (`createApproval`, `getApproval`, `verifyReceipt`).
- Remote MCP (where supported): https://grant-approve.vercel.app/api/mcp
- Privacy: https://grant-approve.vercel.app/privacy
- No credentials, card data, or raw customer PII are requested or sent to Grant.

● Protected by Grant · Zero-custody consent infrastructure

Grant never sees your credentials or payment details. It only records what you allowed.
